# 🛒 BootService Store

Una plataforma de comercio electrónico moderna, intuitiva y completamente responsiva, desarrollada con tecnologías web estándar para ofrecer una experiencia de compra fluida.

---

## 🛠️ Tecnologías Utilizadas

El proyecto fue construido utilizando las siguientes herramientas:

* **Estructura:** HTML5 para un marcado semántico y accesible.
* **Estilos:** [Bootstrap 5](https://getbootstrap.com) para un diseño responsivo y componentes estilizados.
* **Interactividad:** JavaScript (Vanilla JS) para la lógica del carrito, filtros y peticiones.
* **Persistencia de Datos:** MySQ para gestionar el inventario, usuarios y compras.

---

## ⚙️ Requisitos Previos

Antes de comenzar, asegúrate de tener instalado lo siguiente en tu equipo:
* Un navegador web moderno (Chrome, Edge, Firefox, etc.).
* Un servidor local o entorno para ejecutar la base de datos **Node.js**.

---

## 📦 Instalación y Configuración

Sigue estos pasos para ejecutar el proyecto de forma local:

1. **Clona este repositorio en tu máquina:**
   ```bash
   git clone https://github.com
   ```

2. **Ingresa a la carpeta del proyecto:**
   ```bash
   cd tu-repositorio
   ```
